# Invest Blog Assistant — v1.3

**Что нового:** анализ риска долгосрочного портфеля и финансовые цели. Работает поверх v1.2 с исправлением истории ETF LQDT. Никаких торговых поручений и автопокупок.

## Безопасное обновление (Ubuntu + uv + ~/Downloads)

1. Остановите Telegram-бота и веб-сервер (`Ctrl+C`).
2. Из директории `~/Projects/invest_blog_assistant` сделайте резервную копию кода и SQLite.

```bash
cd ~/Projects/invest_blog_assistant
mkdir -p backups
cp -a invest_blog backups/invest_blog_before_v1_3
uv run python - <<'PY'
from sqlite3 import connect
from pathlib import Path
from datetime import datetime
from invest_blog.config import Settings
source=Settings.load().db_path
if not source.exists():
    raise SystemExit(f'База не найдена: {source}')
target=Path('backups')/f'before_v1_3_{datetime.now():%Y%m%d_%H%M%S}.sqlite3'
with connect(source) as db, connect(target) as backup:
    db.backup(backup)
print('Резервная копия:', target)
PY
```

3. Распакуйте **патч** из Downloads (не полную версию):

```bash
unzip -o ~/Downloads/invest_blog_v1_3_patch.zip
uv sync --extra dev
uv run python -m pytest -q
```

4. Посмотрите диагностику:

```bash
uv run python -m invest_blog.cli risk
uv run python -m invest_blog.cli web --port 8000
```

Откройте `http://127.0.0.1:8000`, вкладки **«Риски»** и **«Цели»**.

Уже сохранённая история операций и котировок не стирается. При первом запуске веба автоматически создаётся таблица `financial_goals`, прежние таблицы остаются неизменными.

## Контроль рисков

Входные параметры `.env`:

```dotenv
BOND_TARGET=0.60
MAX_POSITION_WEIGHT=0.15
```

`BOND_TARGET` — ориентир доли облигаций от общей стоимости портфеля. `MAX_POSITION_WEIGHT` — ориентир концентрации по эмитенту **внутри облигационной части**, если доступна достоверная группировка через `issuerUid`. Это не ограничение для отдельных торговых UID.

На вкладке «Риски» анализируются:
- расхождение доли облигаций с личной целью;
- концентрация по эмитентам **по подтверждённым текущим рублёвым номиналам** (не рыночной стоимости), без угадывания эмитента по названию;
- доля текущего номинала облигаций с погашением в одном году;
- актуальность снимка.

Общий балл — **эвристическая оценка доступных проверок**, не рейтинг безопасности. Если недостаточно подтверждённых факторов или снимок устарел, балл не показывается. Он не оценивает дефолт, процентный, ликвидный, валютный риск, санкции, рейтинги или качество отчётности эмитента. Отсутствие тревог не означает безопасности.

## Финансовые цели

Создаются/редактируются/удаляются во вкладке «Цели»; хранятся локально в SQLite:

- `portfolio_value`: стоимость портфеля, ₽;
- `monthly_income`: средние купоны + дивиденды, ₽/мес.;
- `monthly_coupons`: средние купоны, ₽/мес.;
- `bond_share`: текущая доля облигаций, %.

Для средней выплаты берутся только **завершённые месяцы** из последних 12, для которых загружена история операций **по всем текущим счетам**; требуется минимум три месяца. Неизвестные месяцы не становятся нулевыми. Налоги и комиссии отдельно не вычитаются, другие валюты не переводятся в рубли. Прогресс — отношение текущего значения к цели, не прогноз достижения к сроку.

## API локального дашборда

- `GET /api/risk` — диагностика без раскрытия account ID или токена.
- `GET /api/goals` — текущие цели и фактический прогресс.
- `GET /api/editor-token` — токен защиты действий (только для локального интерфейса).
- `POST /api/goals` — добавить цель.
- `PUT /api/goals/{id}` — изменить цель.
- `DELETE /api/goals/{id}` — удалить цель.

Для изменения целей нужен HTTP-заголовок `X-CSRF-Token`. Веб-сервер запускается **только на 127.0.0.1**, а доступ по иным Host отклоняется. Не пробрасывайте порт в сеть без отдельной аутентификации.

## Границы релиза

v1.3 **не** реализует торговые рекомендации «купить X» или автоматические сделки. Историческая доходность TWR/XIRR, AI-редактор и подключение зарубежных/криптовалютных портфелей оставлены на следующие версии согласно roadmap.

Для пересчёта аналитики после новых операций можно выполнить `uv run python -m invest_blog.cli sync --days 365`; цель и её настройки при этом не изменяются.
