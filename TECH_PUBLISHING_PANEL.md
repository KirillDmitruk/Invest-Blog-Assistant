# Content Hub — VK + Telegram publishing dashboard

## Подготовка

1. Добавь бота в администраторы **Kir in Tech News** с правом публиковать сообщения.
2. В `.env` укажи настоящий username публичного канала (например `@my_public_channel`), **не username бота**:

```dotenv
TELEGRAM_BOT_TOKEN=...
TECH_TELEGRAM_CHANNEL_ID=@your_real_channel
VK_GROUP_ID=...
VK_ACCESS_TOKEN=...
VK_AUTO_PUBLISH=false
TECH_TG_AUTO_PUBLISH=false
VK_NEWS_TIMES=10:00,13:00,16:00,19:00
TIMEZONE=Europe/Moscow
```

Токены не передавай никому и не коммить в Git. `TECH_TELEGRAM_CHANNEL_ID` — это не `TELEGRAM_CHANNEL_ID` инвестиционного блога.

## Тест Telegram

```bash
uv run python -m invest_blog.cli tg-test
uv run python -m invest_blog.cli tg-test --publish --confirm PUBLISH
```

Вторая команда **реально отправит** одно тестовое сообщение в канал. Понадобится действующий `TELEGRAM_BOT_TOKEN` и добавленный администратором бот.

## Включение расписания

После проверки перевода и канала:

```dotenv
VK_AUTO_PUBLISH=true
TECH_TG_AUTO_PUBLISH=true
```

Перезапусти `make bot` и `make web`. Планировщик живёт в боте; веб-интерфейс только отображает статус конфигурации/SQLite и позволяет явно отправить одну новость. Статус `включён` означает значение `.env`, а **не гарантию**, что процесс бота работает; следующий слот рассчитан по расписанию, а не прочитан из работающего планировщика.

## Панель

Открой `http://127.0.0.1:8000/` → Tech & Gadgets → Обзор и редактор → **Kir in Tech News · автопубликация**. Там есть:

- флаги VK и Telegram;
- ближайшее плановое время по часовому поясу приложения;
- число подтверждённых публикаций сегодня, занятое количество VK-слотов и ожидающие Telegram новости;
- историю последних 35 записей и неопределённых исходов;
- кнопку «Опубликовать сейчас (1 новость)» с явным подтверждением в браузере.

Кнопка отправляет **реальную новость** в VK и, если включён Telegram, синхронизирует соответствующий опубликованный текст. Оставлены ежедневный лимит VK 4 и защита от дублей; исход `uncertain` требует ручной проверки.

## Ограничения

- Нет изображений — следующий этап.
- Бот и веб должны запускаться с одинаковым `.env` и одной базой SQLite.
- История показывает подтверждения и ошибки статуса (`reserved` / `uncertain`), но не все текстовые ошибки выполнения; ошибки без попытки резервирования пока остаются в логах бота.
- Если `VK_AUTO_PUBLISH=false`, публикация кнопкой не выполняется.
- Пока нет отдельной кнопки «только Telegram» в веб-интерфейсе: можно использовать `tg-news` для догрузки уже подтверждённых VK-публикаций.
