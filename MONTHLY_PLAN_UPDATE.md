# Content Hub — сохранённый месячный план покупок

## Что изменилось

В разделе «Распределение средств» сверху появился «Месячный инвестиционный план»: сумма вводится один раз, курс USD/RUB загружается с официального сайта Банка России, результат и выполненные покупки сохраняются в SQLite. Фиксируются сумма, режим подушки, курс и дата курса на момент создания. Повторное создание плана того же месяца запрещено, чтобы случайно не потерять отметки. При смене месяца открывается его собственный план.

Стратегия: 40% в подушку (или 10% после накопления), остаток: РФ 20%, зарубежные 45%, крипта 20%, золото 10%, высокий риск 5%. Внутри зарубежных 40/20/20/20; в крипте BTC 50%, ETH 25%, SOL 10%, TON/BNB/TRON по 5%. SOL/TON/BNB/TRON — 1-го числа, BTC/ETH и зарубежные направления — в каждую пятницу месяца. Суммы по каждой позиции рассчитаны в рублях, ориентировочные USD по сохранённому курсу ЦБ. Старые независимые калькуляторы не удалены.

Курс ЦБ служит ориентиром, не включает обменные комиссии, рыночный курс кошелька и проскальзывание. Если сайт ЦБ недоступен, новое сохранение плана отклоняется вместо использования вымышленного курса; ранее сохранённые планы открываются нормально.

## Установка

1. Остановите `make web` и сохраните резервную копию базы `data/drafts.sqlite3` с помощью SQLite backup API (или при остановленном приложении скопируйте файл).
2. В каталоге проекта сохраните исходники: `cp invest_blog/dashboard.py backups/dashboard_before_monthly.py` и `cp invest_blog/web_static/index.html backups/index_before_monthly.html`.
3. `unzip -o ~/Downloads/content_hub_monthly_investment_plan_patch.zip`
4. `PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 uv run python -m pytest -q`
5. `make web`, далее `Ctrl + Shift + R` в браузере.

Создаются две новые таблицы: `monthly_investment_plans` и `monthly_investment_purchases`. Миграция идемпотентна (`CREATE TABLE IF NOT EXISTS`). Она не трогает портфель брокера, черновики и новости.

## Проверка

Выберите месяц → введите сумму и состояние подушки → «Сохранить план на месяц» → отметьте покупку → обновите страницу → убедитесь, что отметка осталась. После смены месяца отобразится отдельный план. Новое сохранение существующего плана намеренно блокируется.

Для будущего улучшения: отдельный учёт фактических трат и изменения месячного плана с подтверждением; сейчас галочка означает факт выполнения по утверждению пользователя, а не автоматически подтверждённую сделку.
