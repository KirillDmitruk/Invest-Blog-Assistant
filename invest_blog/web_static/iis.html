Другие активы счёта

Текущий разбор сосредоточен на облигациях. Эти позиции входят в счёт, но не в распределение облигационного риска.

Как устроен анализ

    Разбор помогает принять решение вручную. Торговые заявки и вывод средств не выполняются. Для решения о продаже нужны цена выхода, ликвидность, комиссии и актуальное состояние эмитента. Закрытие ИИС и вывод денег требуют отдельной проверки условий счёта.

    Подтверждённые данные

    Не угадывай эмитента по названию. Для объединения выпусков используй один идентификатор, например ИНН. Рейтинг указывай для конкретного выпуска; рейтинг эмитента не переносится автоматически на субординированный долг.
