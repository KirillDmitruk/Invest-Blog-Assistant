# Content Hub v2.0.1 — Tech RSS

- Tech-лента с источниками The Verge, Ars Technica, TechCrunch, Engadget, IEEE Spectrum, MIT Technology Review, NASA.
- Категории: технологии, AI, рынок/IPO, робототехника, гаджеты/прототипы, DIY/электроника, 3D-печать, космос.
- RSS/Atom XML-парсер, отсев некорректных ссылок, очистка HTML, дедупликация по ссылке, даты UTC, сохранение в SQLite.
- Раздельный статус и ошибки каждого источника. Сбой RSS не удаляет новости.
- Веб-лента с фильтром категорий, ссылками, скрытием новостей и созданием Tech-черновика (без AI).
- При запущенном Telegram-боте: проверка при старте и каждые 2 часа; для проверки из CLI: `uv run python -m invest_blog.cli tech-news`.
- Сохранены предыдущие инвестиционные API, Telegram-команды и черновики. Публикация Tech в Telegram/VK и AI **не добавлены**.
- Внешние источники на реальной сети пользователя нужно проверить после установки.
