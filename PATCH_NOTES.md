# Исправление отчётов T-Invest API

Причина: `GetOperationsByCursor` возвращает `OperationItem.type` (например, `OPERATION_TYPE_COUPON`), а исходный код фильтровал `operationType`. Поэтому выплаты и пополнения не попадали в отчёты. Проверено по официальной документации:
https://developer.tbank.ru/invest/api/operations-service-get-operations-by-cursor

## Что изменено

- `invest_blog/posts.py`: чтение правильного `type` (с совместимостью для старых данных), корректный подсчёт купонов, дивидендов, пополнений и погашений. В `/monthly` добавлена сводка покупок (количество и общая сумма), без перечня сделок. `/weekly` по-прежнему без покупок.
- `invest_blog/tinvest.py`: проверка структуры ответа операций, логирование количества записей по страницам и явное сообщение об ошибке, если поле типа отсутствует.
- `invest_blog/cli.py`: команда `diagnose` для безопасной диагностики операций за период, без токена и идентификаторов счетов в выводе.
- `tests/test_posts.py`: регрессионные тесты с реальным полем `type`.

## Как применить к существующему проекту

Остановите бота (`Ctrl+C`) и выполните, находясь в корне проекта:

```bash
cp invest_blog/posts.py invest_blog/posts.py.bak
cp invest_blog/tinvest.py invest_blog/tinvest.py.bak
cp invest_blog/cli.py invest_blog/cli.py.bak
unzip -o ~/Загрузки/invest_blog_reports_fix.zip
python -m pytest -q  # если pytest установлен
python -m invest_blog.cli diagnose --start 2026-09-01 --end 2026-09-30
python -m invest_blog.cli preview monthly --date 2026-10-28
python -m invest_blog.cli bot
```

Расположение ZIP замените на ваше фактическое. Архив не содержит `.env`, сертификаты и SQLite-базу и не изменяет их.

Если хотите получить новый отчёт в Telegram, вызовите `/monthly` — команда создаст **новый** черновик. Старый черновик не меняется автоматически.

## Ограничения

- Подсчёт покупок основан на сумме исполненных операций; комиссии и НКД отдельно не перерассчитываются.
- Входящие переводы (`OPERATION_TYPE_INP_MULTI`) отнесены к пополнениям; если не хотите считать внутренние переводы пополнениями, уберите этот тип из `DEPOSIT`.
- Историческая стоимость портфеля за 30 сентября не рассчитывается: показатель стоимости — **текущий**.
- Если реальные операции не видны даже в `diagnose`, проверьте выбранные ID счетов, историю в приложении брокера и при необходимости брокерский отчёт.
