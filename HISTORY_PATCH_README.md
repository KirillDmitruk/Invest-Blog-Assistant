# Патч v1.2: история стоимости портфеля

## Проблема

В v1.2 график «Динамика стоимости портфеля» строился исключительно по сохранённым `portfolio_snapshots`. Команда `sync --days 365` импортирует историю операций, но не историю оценки портфеля: `GetPortfolio` умеет выдавать только актуальный портфель.

## Решение

- Добавлена команда `backfill`, которая восстанавливает **приблизительную** стоимость прошлых дней по исполненным операциям, денежным остаткам на момент последнего снимка и историческим дневным свечам `GetCandles`.
- Для облигаций цена свечи в пунктах переводится в рубли: `close / 100 * nominal`.
- Веб-график отдельно отображает **снимки брокера** (сплошная линия) и **расчётную историю** (пунктир), не смешивая их в одну подтверждённую серию.
- Даты без цены или с устаревшей ценой (>35 суток) пропускаются, а не заполняются нулями.
- Ошибки расчёта и неполная история не перезаписывают предыдущие данные.
- Запросы только на чтение. Токен и `.env` не меняются.

## Установка через uv на Ubuntu

1. Останови бота и веб-сервер (`Ctrl + C`).
2. Сохрани SQLite и свои правки в исходниках, если они есть.
3. Распакуй архив из `~/Downloads` в корень проекта:

```bash
cd ~/Projects/invest_blog_assistant
unzip -o ~/Downloads/invest_blog_history_patch.zip
uv sync --extra dev
uv run python -m pytest -q
```

4. Если история операций ещё не была загружена за год, выполни:

```bash
uv run python -m invest_blog.cli sync --days 365
```

5. Восстанови исторические значения (для 45 бумаг может потребоваться множество запросов):

```bash
uv run python -m invest_blog.cli backfill --days 365
```

6. Запусти дашборд:

```bash
uv run python -m invest_blog.cli web --port 8000
```

Открой http://127.0.0.1:8000 и обнови вкладку браузера. На главной странице появится пунктирная линия до первого сохранённого снимка, если достаточно данных.

## Ограничения (важно)

**Это не точные исторические оценки брокера** и не график доходности (TWR/XIRR). Получить прошлый `GetPortfolio` на произвольную дату нельзя; цены и состав приходится восстанавливать по истории.

- **НКД в прошлых датах не восстанавливается** — историческая оценка облигаций может отличаться от приложения.
- Для **амортизируемых облигаций** используется *текущий* номинал: оценки до амортизации могут быть занижены. При наличии таких выпусков команда выдаёт предупреждение.
- **Валютные активы**, FX, фьючерсы, некоторые корпоративные действия и переводы бумаг требуют отдельной логики. Скрипт откажется считать такие случаи вместо выдачи заведомо неверного графика.
- Для внебиржевых или неликвидных бумаг без цен свечей дни будут отсутствовать.
- Дневная свеча — цена закрытия биржи, не обязательно совпадает с оценкой брокера в момент снимка.
- **Пополнения и выводы влияют на величину портфеля**; изменение линии не означает заработанную прибыль.

Если backfill сообщил об ошибке, пришли её текст **без секретов, токенов и ID счетов**, чтобы адаптировать восстановление к конкретным операциям и инструментам.
