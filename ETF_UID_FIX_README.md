# Invest Blog Assistant v1.2 — History ETF multi-venue fix

## Что исправлено

В истории обнаружены операции по одному ETF `LQDT` (ISIN `RU000A1014L8`) через два торговых UID в режимах TQTF и SPBRU. При этом `positionUid` различается, `assetUid` совпадает. Старый расчёт учитывал отдельные торговые UID как разные ценные бумаги и получал ошибочный отрицательный остаток по первому UID.

`history.py` теперь **только для расчётной стоимости** агрегирует сделки ETF по проверенным совпадающим `assetUid`, ISIN, тикеру, валюте RUB и лотности 1. Группировка применяется по каждому счёту отдельно. Исходные `instrumentUid`, операции и `positionUid` в базе не переписываются. Для рыночной стоимости сначала используются котировки основного режима TQTF на Мосбирже, затем (если отсутствует цена на конкретный день) других режимов. При расхождении цен более 5% за один день этот день исключается и создаётся предупреждение.

**Это не доказательство перевода между площадками**. Расчётный остаток на начало года определяется арифметикой текущих позиций и операций, а не записью «куплено 72 пая». Если история брокера неполная, результат остаётся оценкой. Для полной проверки сравни со своим брокерским отчётом.

## Установка

Останови бота и веб-сервер.

```bash
cd ~/Projects/invest_blog_assistant
mkdir -p backups
cp invest_blog/history.py backups/history_before_etf_uid_fix.py
unzip -o ~/Downloads/invest_blog_etf_uid_fix.zip
uv run python -m pytest -q
```

Ожидается: `88 passed` (при полном наборе предыдущих тестов и нового файла).

## Запуск

Для уже импортированной истории повторный `sync` не нужен:

```bash
uv run python -m invest_blog.cli backfill --days 365
```

Если возникнет другая независимая ошибка операций, ничего автоматически не обнуляй. Чтобы построить проверенный поздний участок:

```bash
uv run python -m invest_blog.cli backfill --days 365 --partial
```

Запуск веб-интерфейса:

```bash
uv run python -m invest_blog.cli web --port 8000
```

Открой `http://127.0.0.1:8000`.

## Что остаётся неточным

- Котировки из исторических свечей — оценка на конец торгового дня, не брокерский NAV.
- НКД по облигациям пока не восстановлен.
- Номиналы амортизируемых выпусков в прошлом могут отличаться.
- Если нет котировок или данных по операциям, дата остаётся пропуском.
- Сохраняй API-токены и номера счетов в секрете; патч их не выводит.
