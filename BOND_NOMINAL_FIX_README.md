# Invest Blog Assistant v1.2 — исправление исторического номинала облигаций

## Почему возникала ошибка

`HistoricalBackfill` использовал только `BondBy.instrument.nominal`.
Если у выпуска номинал отсутствует, стал равен 0 после погашения или задан в другой валюте,
программа останавливалась даже при наличии сведений `initialNominal`.

## Что поменялось

- Положительный `nominal` в **RUB** используется без изменений.
- Если `nominal` пустой/нулевой, `initialNominal` в RUB используется **только для облигации с `amortizationFlag: false`**.
- Для амортизируемых, валютных или нераспознанных выпусков стоимость не придумывается:
  дни, когда бумага была в портфеле, исключаются из расчётной истории и отображается предупреждение с названием/тикером и суффиксом UID.
- Дни без такой бумаги остаются доступны для построения графика.
- Если невозможно рассчитать **ни одной** даты, прежняя история остаётся в SQLite, а команда объясняет причину.
- Если `BondBy` вернул HTTP 404 (для погашенного/исчезнувшего выпуска), используется безопасная логика отсутствующего номинала. Сетевые ошибки не скрываются.
- Реальный T-Invest API пользовательского счёта не проверялся: интеграционная проверка нужна на месте.

## Установка

1. Остановить Telegram-бота и веб-сервер.
2. В каталоге проекта выполнить:

```bash
cd ~/Projects/invest_blog_assistant
mkdir -p backups
cp invest_blog/history.py backups/history_before_nominal_fix.py
unzip -o ~/Downloads/invest_blog_bond_nominal_fix.zip
uv run python -m pytest -q
uv run python -m invest_blog.cli backfill --days 365
```

Для патча переустановка зависимостей и повторный `sync` не нужны: изменён только код восстановления и тесты.

Если после исправления не восстановилось ни одной даты, проверьте в сообщении предупреждения название бумаги и причину. Для полной истории номиналов амортизируемых облигаций потребуется расчёт по графику амортизаций (отдельный этап).

## Безопасность и точность

- Архив не содержит токенов, `.env`, базу SQLite и локальные сертификаты.
- Используется только T-Invest read-only API.
- Расчётные точки — **приблизительная стоимость** по ценам закрытия, не брокерский NAV и не доходность.
- НКД и исторические изменения номинала амортизируемых облигаций остаются ограничениями исторического расчёта.
