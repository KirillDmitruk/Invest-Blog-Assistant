# Облачные новости Telegram

Канал задаётся переменной репозитория NEWS_TELEGRAM_CHANNEL (теперь @justinvestrofl). Предыдущий канал не служит запасным: без настроенного адреса отправка запрещена. Одна публикация каждые 30 минут, 09:00–22:30 МСК; после 23:00 публикаций нет. Cloudflare проверяет расписание раз в пять минут и запускает workflow telegram-news.yml. Поэтому возможна задержка запуска относительно границы получаса. Ноутбук и локальный бот не нужны.

Источники: российский рынок, зарубежные рынки, криптовалюты. Используются 16 проверенных RSS: Банк России (пресс-релизы), Смартлаб, Интерфакс, РБК, Коммерсантъ, CNBC (две ленты), Bloomberg, Financial Times, ФРС, SEC, CoinDesk, Cointelegraph, The Block, Decrypt и ForkLog. [Полная проверка и ограничения](NEWS_SOURCES.md). Каналы-примеры использованы как ориентир подачи; автоматического копирования их постов нет.

Если RSS лишь повторяет заголовок, для разрешённых адресов статей Смартлаба читается блок текста: без комментариев, меню и рекламных примечаний. Размер ответа ограничен, редиректы запрещены. Редактор Cloudflare AI получает только заголовок, текст новости (до 3000 символов) и направление. Формат: выразительный заголовок и один-три коротких абзаца без обязательной одинаковой анкеты. Программа добавляет оформление и источник. Проверяются схема, русский язык, длина, новые числовые значения, числовые масштабы и очевидные призывы к покупке/реклама. Это не независимая проверка всех утверждений: качество зависит от исходного RSS и ответа модели. Прогнозы нельзя выдавать за утверждённые решения. Неподходящий ответ или нехватка фактов — пропуск слота.

Свежесть — до 24 часов, без будущих дат. Направления чередуются по доступности; точные ссылки и нормализованные заголовки защищены от повторов. Разные формулировки одной истории пока могут потребовать дополнительной редакторской проверки.

Перед отправкой сохраняется зашифрованная запись попытки в отдельной ветке automation/telegram-news-state. После неопределённого результата автоматического повтора этой новости нет. Сбой сохранения блокирует отправку. Максимум два обращения к ИИ за один запуск. Публикация использует существующие GitHub Secrets CF_ACCOUNT_ID, CF_AI_TOKEN, SIGNALS_BOT_TOKEN, PULSE_STATE_KEY; новых ключей не нужно. Токены, кошелёк и портфель в логах и публичном статусе отсутствуют. Бесплатная квота Cloudflare ограничена; при её исчерпании новости пропускаются, платное переключение не предусмотрено.

Переключатель репозитория CLOUD_NEWS_ENABLED включает workflow. Для временной паузы: Actions → Telegram investment news → ⋯ → Disable workflow; для возобновления Enable workflow. Сначала проверять журнал, затем включать: неопределённые попытки не повторяются.

В локальном хабе отображается публичный статус облачного расписания. Локальный отправитель отключается, чтобы два независимых процесса не публиковали одновременно. Локальная ручная очередь не синхронизируется с облачной — интерфейс явно это показывает.

Проверка: `python -m pytest tests/test_news_editor.py tests/test_cloud_news.py -q`, `node tests/test_demo_scheduler.mjs`.

Пост начинается с жирного заголовка, без подписи категории. При наличии иллюстрации в статье Смартлаба выбирается первая картинка внутри текста, без рекламы и меню, с адресом /uploads/ на этом же сайте (JPEG/PNG). Если текст укладывается в 1024 символа Telegram, картинка скачивается с ограничением размера и передаётся файлом, затем отправляется одна фотография с подписью; иначе сохраняется полный текст и включается крупное превью статьи. Автоматического создания мемов нет. Неопределённая отправка фотографии не повторяется текстом; только явный отказ HTTP 400 допускает текстовый вариант.
