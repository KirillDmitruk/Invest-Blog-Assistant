# Виртуальные фьючерсы Т-Инвестиций

Существующая вкладка «Торговый бот» показывает отдельный облачный счёт с начальным капиталом **1 000 000 ₽**. Старый локальный счёт и криптосимулятор USD 10 000 не меняются. Реальных заявок брокеру нет: транспорт разрешает только каталог, параметры контракта, свечи, котировки и торговый статус. Номера счетов симулятору не передаются.

Мониторинг запускается примерно каждые 15 минут, анализ Cloudflare — раз в 2 часа. Ноутбук можно выключить. Расписание GitHub может задерживаться. Если рынок закрыт, поиск свежих данных повторяется примерно через 30 минут. Отсутствие сделки — допустимый результат анализа; при недоступности ИИ автоматического платного переключения нет.

Анализируется выборка до восьми разных базовых активов: ближайшая действующая серия, приоритет валютам, нефти, индексам, золоту и газу. Фактический охват виден в счёте; это не сканирование всех фьючерсов. Используются завершённые 15-минутные свечи, SMA10/SMA30, ATR14. Новости и недельный тренд в этот анализ не подмешиваются. Самооценка модели не является вероятностью прибыли.

Начальные ограничения: риск сделки 1% капитала, суммарный риск до стопов новых входов 5%, ГО с запасом не больше 30%, максимум четыре позиции и десять контрактов на позицию. Дневной лимит потерь 3%, просадка 10% останавливают новые входы. Запас ГО 25%. Стоп 2 ATR, цель 4 ATR. Выход перед окончанием торгов серией — при доступной торговле; автоматического переноса позиции нет.

PnL считается через шаг цены и его рублёвую стоимость. Комиссия модели 2 ₽ на контракт на сторону, проскальзывание один тик. Между циклами проверяются завершённые минутные свечи после минуты входа. Если в одной свече достигнуты оба уровня, выбирается стоп; гэп исполняется по худшей цене открытия с проскальзыванием. Это приблизительная симуляция, без гарантированной ликвидности, полного клиринга, налогов и поставки. При длительном пропуске данных новые входы блокируются.

Состояние шифруется отдельным ключом `TINVEST_PAPER_STATE_KEY`, ветка `automation/tinvest-paper-state`. Не помещать ключ в код или сообщения. Локальная копия ключа защищена Windows DPAPI. Для остановки облачных циклов отключить workflow **T-Invest virtual futures** в GitHub Actions; это также остановит виртуальный мониторинг. Существующие реальные позиции в Walt не затрагиваются.

История виртуальных сделок не удаляется при сохранении. Для графика и объяснений хранятся последние 500 записей, для технического журнала — 150 циклов; итог капитала накопительный. Зашифрованный снимок сжимается. При достижении предела размера базы 4 МБ потребуется архивирование: бот остановит сохранение с ошибкой, а не сбросит счёт.

Запуск хаба: `.\hub web`, затем вкладка «Торговый бот». Отдельный локальный торговый процесс не нужен. Настройки облачного счёта в локальном интерфейсе доступны для просмотра; локальные команды его не изменяют.

Ограничения интервалов свечей сверены с [документацией Т-Банка](https://developer.tbank.ru/invest/services/quotes/faq_marketdata).
