# Облачный обзор рынка через GitHub Actions

Это отдельный экспериментальный обзор публичных рынков Lighter. Он не переносит вход Walt, не видит баланс или позиции и не отправляет торговые заявки. Для сделки нужен локальный хаб со свежей проверкой Walt и твоим подтверждением. Наличие тикера на Lighter не подтверждает доступность в Walt.

## Что запускается

`Cloud market signals` читает все активные бессрочные рынки Lighter с множителем 1, до 300 без молчаливого обрезания. Для каждого проверяется непрерывная история минимум 240 закрытых часовых свечей. EMA20/50, RSI, ATR, сутки/неделя дают технических кандидатов. Объём последних 24 закрытых часов — от 1 млн; суточное изменение по модулю меньше 10%; ATR до 2,8%. Это отдельный упрощённый фильтр, а не полная стратегия Walt: фандинг, OI, расходы и исполнимость Walt здесь не подтверждены.

Cloudflare рассматривает до 8 технических кандидатов одним запросом, принимает или отклоняет готовое направление. Новости ФРС/CoinDesk за 48 часов — ограниченный и непроверенный RSS-контекст. Модель не задаёт маржу, плечо, стопы или сделки. Без ключей/при ошибке/квоте отчёт явно говорит, что проверки ИИ нет; технический кандидат не превращается в подтверждённый ИИ сигнал. Остальные рынки остаются в полном JSON-отчёте.

## Первый запуск

1. В GitHub открой **Actions → Cloud market signals → Run workflow**. Оставь `send` выключенным. Кошелёк и Telegram не вызываются. Публичные результаты находятся в Artifacts → cloud-market-report.
2. Для ИИ: **Settings → Secrets and variables → Actions → Secrets**: `CF_ACCOUNT_ID` и `CF_AI_TOKEN` с правом Workers AI Run. Модель фиксирована: `@cf/meta/llama-3.1-8b-instruct-fp8-fast`. Платного переключения нет. Оставь аккаунт Cloudflare на Free без карты; доступность проверяется первым реальным запросом.
3. Для Telegram добавь `SIGNALS_BOT_TOKEN` и `SIGNALS_CHAT_ID` — **числовой ID твоего личного чата**, а не ID бота или канала. Сначала напиши боту `/start`. Получить свой ID можно из уже полученного ботом обновления `message.chat.id`; не публикуй результат `getUpdates`, он содержит личные сообщения. Код проверяет getMe/getChat и блокирует канал, группу и адрес самого бота. Не используй публичный Kir in Tech для торговых уведомлений.
4. Повтори ручной запуск с `send=true`. Это отправит один обзор, но не сделку.
5. После проверки создай **Variables → CLOUD_SIGNALS_ENABLED = true**. Расписание: `17 */2 * * *`, UTC, каждые два часа круглосуточно на 17-й минуте (по Москве 01:17, 03:17, …, 23:17). По умолчанию расписание отключено. Для работы по расписанию файл должен находиться в основной ветке.

Не загружай `.env`, базу хаба или авторизацию Walt в репозиторий. В публичных артефактах сохраняются только рыночные данные и обзор. Отдельной подписки ChatGPT/Grok этот вариант не использует.

## Состояние и повторные отправки

Все запуски используют одну очередь без отмены текущего запуска. В служебной ветке `automation/cloud-signals-state` хранится только до 100 маркеров отправок без токена, текста личных сообщений и открытого chat_id. Нужен `contents: write` у workflow. Ошибка чтения состояния запрещает отправку. Маркер attempted записывается **до** Telegram; после подтверждения меняется на sent. Потеря ответа может привести к пропущенному уведомлению, но не к автоматическому повтору. Ключ — двухчасовой интервал UTC и отпечаток получателя. Удаление ветки/истории снимает защиту, поэтому не удаляй их для повторной отправки. Это не журнал сделок и не финансовое состояние.

## Ограничения площадок

Actions не является гарантированным торговым сервером. Расписание может задерживаться, задания — пропускаться; публичное расписание может отключиться после 60 дней неактивности. Нет постоянного процесса или контроля открытых позиций. В бесплатном приватном репозитории учитываются минуты; публичные рыночные артефакты видны другим людям. Эксперимент не означает, что GitHub одобрил использование Actions для эксплуатации бота: условия ограничивают задачи, не связанные с разработкой/тестированием/развёртыванием/публикацией проекта. Перед длительной эксплуатацией нужно учитывать это ограничение.

Источники: [GitHub schedule](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule), [условия GitHub](https://docs.github.com/en/site-policy/github-terms/github-terms-for-additional-products-and-features), [Cloudflare Free AI](https://developers.cloudflare.com/workers-ai/platform/pricing/).

Локальная проверка: `python -m pytest tests/test_cloud_signals.py -q`. Обзор без отправки: `python -m invest_blog.cloud_signals`. Эти команды не используют авторизацию Walt и не открывают позиции.
