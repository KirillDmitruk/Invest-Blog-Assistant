# Интерфейс демо-счетов

Т-Инвестиции: открытые позиции оформлены карточками в стиле Walt. ГО с запасом, число контрактов, вход, последняя котировка, стоп и тейк показаны отдельно. Цены фьючерсов подписаны в пунктах; PnL и ГО — в рублях. PnL позиции остаётся до комиссий. В локальном режиме сохранена кнопка виртуального закрытия; облачный режим показывает снимки.

Walt: график показывает сохранённую полную стоимость виртуального кошелька в долларах: cash + нереализованный PnL. Комиссии и фандинг уже отражены в cash. Начальный бюджет выделен пунктиром. Старый баланс не пересчитывается по новым котировкам задним числом. Если истории ещё нет, используются только подтверждённая точка обновления стратегии и текущий облачный снимок.

После каждого облачного цикла сохраняется точка equity_history. До 2016 последних оценок, без дублей одного времени. Оценки с неполными котировками помечены. Наведение на точку показывает время и сумму. Обе страницы используют один SVG-компонент, без загрузки внешней библиотеки.

Проверка: `python -m pytest tests/test_paper_perps.py tests/test_paper_routes.py tests/test_paper_boundaries.py -q`, `node tests/browser_demo_cards_chart.cjs`.

Оба экрана делятся поровну: позиции слева (список прокручивается), компактный график справа, история сделок на всю ширину ниже. На узком экране блоки располагаются последовательно. Процент рядом с текущим PnL — доходность на выделенное обеспечение: PnL / маржа для Walt и PnL / ГО с запасом для Т-Инвестиций. Это не изменение цены актива. Текущий PnL и процент отображаются до комиссий; в Walt также до учёта фандинга. При отсутствии положительного обеспечения процент не подставляется.
