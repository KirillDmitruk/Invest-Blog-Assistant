# Ликбез: интересные темы и примеры компаний

Рубрика использует 12 практических тем вместо автоматического выбора одного
словарного термина. Отбор учитывает недавние темы, совпадения с актуальной повесткой
и ротацию. Это редакционный выбор, а не измерение популярности всей аудитории.

Облако читает до 40 публичных заголовков РБК/Интерфакса за 7 дней. ИИ выбирает из
допустимых неповторяющихся кандидатов и редактирует проверенный опорный текст.
Данные портфеля и счетов в эти запросы не передаются. Новости служат сигналом
интереса к теме, а не источником финансовых показателей для образовательного поста.

Структура: интересный вопрос, простое объяснение, условный расчёт, ограничения,
примеры компаний с тикерами и вопрос читателю. Нет обязательной одинаковой анкеты.
У компаний предлагаются конкретные вопросы для разбора, без выдуманных актуальных
мультипликаторов, прибыли и прогнозов. В теме мультипликаторов отдельно приведён
исторический ROE Группы Сбер по МСФО за 2025 год с официальным источником.
Эта вставка формируется кодом и не переписывается моделью.

Проверки модели ограничены схемой, длиной, русским языком, отсутствием новых
числовых фактов и неподтверждённых примеров. Это не доказательство фактической
верности любого текста. При ошибке, квоте или отказе ИИ используется редакционный
опорный текст, а не пустая заготовка и не платный запасной провайдер.

В редакции предлагаются три темы с объяснением выбора. При обновлении архивируются
только старые резервные темы без связанного черновика. Выбранные темы, начатые
и завершённые материалы, расписание и история остаются. Пользовательская тема
вне каталога остаётся ручным черновиком с явными подсказками, без выдуманного анализа.

Для проверки облачного текста запустить workflow `Private Pulse drafts`,
включив `preview_lesson=true`: он использует только публичные материалы, не читает
портфель и не отправляет сообщение в Telegram. Обычное расписание доставки
черновиков рубрики остаётся прежним. Повтор уже доставленного недельного поста
сам по себе при обновлении кода не создаётся.
