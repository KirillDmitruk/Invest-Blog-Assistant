# Grok через коннектор · без xAI API

Хаб собирает рыночные данные Т-Инвестиций. Grok анализирует их в твоём чате и возвращает одно решение в хаб. Отдельный ключ xAI API не используется; условия и лимиты твоего аккаунта Grok продолжают действовать. Кнопка в хабе готовит данные, сообщение в Grok запускает анализ.

## Локальный запуск на Windows

В папке `C:\Projects\Invest-Blog-Assistant`:

```powershell
# Один раз: создать отдельный бесплатный секрет коннектора в .env.
.\hub grok-key
# В одном терминале:
.\hub web
# В другом терминале:
.\hub grok-connector
```

Коннектор слушает только `127.0.0.1:8769`. Это отдельное приложение без редакции, доступа к файлам, веб-настроек и реального портфеля. Есть только два инструмента: `get_prepared_market_analysis` и `submit_paper_decision`. Каждый запрос требует `Authorization: Bearer <GROK_CONNECTOR_TOKEN>`.

Секрет создаётся на ноутбуке. Это **не ключ xAI и не токен брокера**. Не пересылай его в чат, не добавляй в URL и не сохраняй в Git. `XAI_API_KEY` и `TRADING_AI_API_KEY` для режима коннектора не нужны. Существующий `TINVEST_TOKEN` остаётся у хаба для чтения рынка.

## Внешний адрес и Grok

Grok не видит localhost: нужен внешний HTTPS-адрес **только порта 8769**. Не публикуй основной веб-порт хаба 8000.

Официальная инструкция Grok предлагает Cloudflare Tunnel как бесплатный вариант:

```powershell
# Однократная установка из официального источника:
winget install --id Cloudflare.cloudflared
# В новом терминале после установки:
cloudflared tunnel --url http://127.0.0.1:8769
```

Скопируй выданный адрес `https://…trycloudflare.com`. При желании добавь в `.env` строку `GROK_CONNECTOR_PUBLIC_URL=https://…trycloudflare.com` и перезапусти веб и коннектор. Секрет в адрес не добавляй. Туннель передаёт запросы через инфраструктуру Cloudflare. Grok получает подготовленные рыночные данные и виртуальный счёт; реальные номера счетов, токены, баланс ИИС и редакторские материалы не передаются.

В [Grok → Connectors](https://grok.com/connectors): **New Connector → Custom**:

- Название: `Content Hub · PAPER`.
- URL: `https://…trycloudflare.com/mcp`.
- Авторизация: Bearer token / API key in header. Имя заголовка `Authorization`, значение `Bearer ` и значение `GROK_CONNECTOR_TOKEN` из твоего `.env`. Если интерфейс предлагает специальное поле Bearer token, вставь только сам токен.

**Авторизация в твоём аккаунте Grok ещё не проверена.** Если интерфейс предлагает только OAuth, не выбирай «без авторизации»: понадобится отдельная OAuth-интеграция. Этот сервер не реализует OAuth. Не вставляй секрет в чат Grok вместо настроек коннектора.

Реализован MCP Streamable HTTP с JSON-ответами, без SSE. Поддерживаются версии 2025-03-26, 2025-06-18 и 2025-11-25. Локальный тест MCP не доказывает совместимость интерфейса аккаунта или доступность сервиса в регионе. Полный вызов из твоего Grok нужно проверить после подключения.

## Анализ и виртуальная сделка

1. В **Торговый бот → Риск и ИИ** выбери **Grok · коннектор, без xAI API**. Проверь ограничения и разреши новые входы, если нужно виртуальное исполнение. Сохрани настройки до подготовки.
2. Выбери наблюдаемые контракты либо **выборку рынка**. Выборка: каталог доступных через API фьючерсов, ближайшая действующая серия, до восьми разных базовых активов. Это ограниченный набор, не лучшие восемь контрактов и не весь рынок.
3. Нажми **Подготовить анализ рынка**. Сбор может занять несколько минут. В пакет входят свечные признаки, цена, шаг/стоимость шага, обеспечение, экспирация, риск и виртуальные позиции. Новостей и стакана в этой версии нет. Пропущенные данные отмечаются.
4. Нажми **Скопировать запрос для Grok** и отправь его в Grok с подключённым Content Hub. Кнопка не запускает Grok автоматически.
5. Grok читает пакет и вызывает `submit_paper_decision`: `analysis_id`, `uid`, `long`/`short`/`close`/`hold`, самооценка и объяснение. Хаб заново получает цену и проверяет срок контракта, риск и состояние счёта. Размер рассчитывает хаб. Ответ и результат проверки появятся в карточке анализа; исполненные виртуальные действия — в журнале и позициях. Экран обновляется раз в минуту, есть ручное обновление.

Пакет действует 10 минут. Новый пакет заменяет старый. Пауза, изменение настроек или состава позиций блокируют вход по старому пакету. Повтор обработанного `analysis_id` возвращает прежний результат без второй сделки. На одной свече решение не исполняется дважды. Grok может выбрать `hold`, хаб может отклонить вход.

Процесс `trade-start` в режиме коннектора **не вызывает платный API и не запускает Grok**. Он продолжает переоценку и виртуальные защитные выходы. После входа выбранный контракт добавляется в наблюдение. Для защитных проверок процесс и компьютер должны работать.

## Остановка и отзыв доступа

Останови коннектор и туннель через `Ctrl+C` в их терминалах. Для отзыва секрета останови коннектор, удали `GROK_CONNECTOR_TOKEN` из `.env`, снова выполни `grok-key`, обнови авторизацию в Grok. Менять брокерский токен не требуется.

Временный адрес туннеля меняется при перезапуске: обнови URL в Grok. Автозапуск и публичный туннель автоматически не устанавливаются.
