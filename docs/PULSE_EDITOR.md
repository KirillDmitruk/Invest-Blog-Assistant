# Посты для Пульса в личном Telegram-боте

Расписание по Москве сохраняется: понедельник 10:00 — план недели, среда 10:00 — бумага недели, пятница 10:00 — ликбез, суббота 10:00 — недельный отчёт; первого числа 11:00 — месячный отчёт.

Cloudflare каждые пять минут проверяет, попало ли время в окно рубрики, и при необходимости запускает `pulse-drafts.yml`. Проверка повторяется не чаще раза в полчаса, чтобы пережить задержки GitHub. Внутри задания зашифрованная отметка по рубрике, периоду и получателю защищает от повторной отправки. Неопределённый результат отправки не повторяется вслепую. Это доставка черновиков в личный бот, а не публикация в Пульс или канал.

Для бумаги недели используются свежие чтения API. Последние двенадцать идентификаторов исключаются из выбора. Сначала рассматриваются бумаги портфеля; если подходящих новых нет, поиск продолжается по ограниченному списку российских акций. В первом обновлённом выпуске Сбер исключён отдельно, поскольку он уже был разобран. Наличие бумаги в портфеле не приписывается бумагам из общего каталога.

Биржевая котировка обязательно имеет время. Во время нормальной торговой сессии она не старше двадцати минут; при закрытой сессии допустима последняя цена за четыре дня с явно указанной датой. Цена облигации отображается в процентах от номинала без НКД. Для выпуска указываются только доступные условия и будущий купон из календаря. Неподтверждённые доходность, рейтинг, отчётность и дивиденды не выдумываются.

ИИ Cloudflare пишет короткие пояснения по публичной карточке и найденным сообщениям из ограниченных RSS за последнюю неделю. Цифры и даты вставляет код. Суммы счетов, размеры позиций и номера счетов в модель не передаются. Если ИИ не ответил или текст не прошёл проверку, приходит явно обозначенная фактическая карточка. При отсутствии свежих данных устаревшая карточка не отправляется.

Финансовые отчёты продолжают считаться по операциям API. Их итоговые суммы ИИ не переписывает. Ликбез ротируется по истории тем. Один обновлённый пример бумаги можно отправить вручную через `example=true`: у него собственная отметка, поэтому повтор того же примера не отправляется и обычное расписание не сбрасывается.
