# Правила демо-эксперимента v2 · 25 ноября 2026

Бюджеты и история не сбрасываются. Каждый счёт сохраняет момент обновления и капитал на эту дату (`strategy_baseline`), а также запись в `strategy_changes`. Хаб показывает результат с момента смены правил отдельно от результата с первоначального старта. Плавающий результат уже существующих позиций входит в это сравнение: это эксперимент по времени, а не изолированная выборка новых сделок.

## Т-Инвестиции

Новые виртуальные входы требуют подтверждения завершёнными часовыми свечами: для лонга закрытие выше SMA10, а SMA10 выше SMA30; для шорта — обратный порядок. Требуется не меньше 35 часовых свечей, последняя — не старше двух часов и полностью закрыта. При нехватке данных вход запрещён, сопровождение позиций продолжается. Модель получает часовой контекст, но не может отменить проверку в коде.

После стопа по контракту действует пауза на один час, независимо от нового направления. Уровни существующих позиций не переписываются. Бюджет, прежние лимиты риска и модель расходов сохраняются. Эти фильтры не гарантируют прибыль.

## Walt

На новые входы: максимум две позиции в одном направлении; расчётный совокупный риск этой стороны до стопов с расходами — не больше 2,5% текущего капитала. Сохраняются прежние общие лимиты, включая риск сделки 1%, плечо до 3× и до четырёх позиций. Уже открытые позиции не ликвидируются при миграции: стопы/цели продолжают проверяться. Пока старые позиции превышают новый предел, дополнительные входы на эту сторону запрещены. Движение цен после входа может менять риск; это ограничитель новых входов, не обещание постоянного риска.

## Доставка аналитики

Независимый таймер Cloudflare проверяет отчёты `cloud-signals.yml` и запускает новый примерно раз в два часа, не полагаясь на нативное расписание GitHub. При неуспешном запуске повтор — не раньше чем через 30 минут, при занятом процессе параллельный запуск запрещён. Успешный запуск сам по себе не гарантирует доступность ИИ: при недоступности провайдера новые входы остаются заблокированными. Старые сигналы не переисполняются. Мониторинг обоих счетов остаётся пятиминутным.
